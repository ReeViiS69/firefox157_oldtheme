# firefox157_oldtheme

firefox got ugly. no default way to change it back, except "unsupported" userChrome.css


you need:
1. about:config
-> toolkit.legacyUserProfileCustomizations.stylesheets true

2. the chrome folder in your firefox profile folder (%appdata%\Mozilla\Firefox\Profiles\"string".default-release-"number"\chrome)
